# 报告输出策略

研究结束优先输出已有完整草稿；没有草稿但有证据时尝试综合。综合失败、预算耗尽或超时则用已保存内容生成阶段报告，不需要额外模型调用。没有证据时说明目标、已完成工作与下一步，不编造结论。

取证/分析预留一次调用与最多 64000 文本预算单位；研究阶段预留剩余时间的 20%（最多 10 秒）给最终综合。总调用、文本和执行时间上限不增加。审查允许带有限定条件的结论，主要缺口最多补查一次。

报告质量与执行状态独立，failed 也可能有报告。技术停止原因保存在 turn.stop 与 RESEARCH_STOPPED 事件中，CLI 的工具详情可查看；报告保留事实层面的限制，避免重复堆叠内部错误。

拒绝或审批过期只整理已有内容，不继续调用模型或检索。流式中断文本标记未完成。数据库不可写或进程被强制终止时不能保证新报告即时保存，恢复时使用最近已保存成果。
