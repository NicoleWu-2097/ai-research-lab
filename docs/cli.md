# Ink 研究项目 CLI

先在一个终端运行 `pnpm dev`，另一个终端运行 `pnpm cli`。需要 HUMAN_ENABLED=true，以及已填写的模型配置。前端使用现成 Ink 与 ink-text-input。

## 独立全屏 TUI 画布与鼠标滚轮滚动

- **独立屏幕缓冲区（Alternate Screen Buffer）**：启动时自动写入 `\x1b[?1049h` 进入独立全屏界面，完全隔离外部终端历史记录；退出（`/quit` 或 `Ctrl+C`）时写入 `\x1b[?1049l` 恢复外部终端原本的命令行界面。
- **鼠标滚轮与触控板捕获（SGR Mouse Mode）**：启用 `\x1b[?1000h\x1b[?1006h` 捕获触控板滑动和鼠标滚轮事件，仅滚动中间固定高度的内容视口并显示右侧视觉滚动条（`┃` / `│`）与行号进度，底部输入框始终锚定在终端最下方，长篇报告的开头段落可随时向上滚轮完整回看。
- **键盘滚动支持**：同样支持 `PgUp` / `PgDn`（或 `Ctrl+U` / `Ctrl+D`）上下翻页滚动内容区。

## 交互式列表与三选项审批（`j` / `h` 上下切换 + `Enter` 确认）

1. **启动项目列表选择**：启动时默认进入交互式项目列表（不自动进入旧项目），每个项目显示自动总结的标题。可使用 `j`（或 `↓`）下移、`h` / `k`（或 `↑`）上移，按 `Enter` 确认进入所选项目、新建项目、进入删除项目列表或查看帮助。
2. **三选项审批交互**：当任务进入待审批（`pending`）状态时，底部输入框自动展示完整换行的审批说明与三个选项：
   - `1. 批准并继续`（澄清模式下进入补充说明输入）
   - `2. 修改查询内容后批准`（预填当前查询供修改，按 `Enter` 提交）
   - `3. 拒绝并结束`
   可通过 `j` / `h` 上下切换并按 `Enter` 确认，按 `Esc` 可返回选项列表。
3. **固定在终端最下方 & 可调整高度的输入框**：
   - 输入框始终固定在终端最底部；
   - 审批原因、查询与子问题均按终端宽度自动多行折行（`wrap="wrap"`），不再因单行截断而显示不全，且自动去除重复的澄清提示文本；
   - 在选项模式下可按 `+` / `-` 快捷键或使用 `/size <行数>` 命令动态调整输入框高度。

## 命令参考（`/help`）

- `/help`：显示完整命令与快捷键说明。
- `/projects`：返回并进入交互式项目列表。
- `/new [问题]`：新建项目（不带参数则进入新建输入模式）。
- `/open <序号|ID>`：按序号或 ID 打开项目。
- `/delete [序号|ID]`：删除项目（省略参数时打开交互式删除选择列表或删除当前项目）。
- `/size <行数>`：调整底部输入框最小高度。
- `/back`（或 `/close`）：返回项目列表。
- `/approval`：输出完整审批详情。
- `/approve [内容]`：批准当前计划或提交澄清内容。
- `/reject`：拒绝当前计划。
- `/report`：重新输出当前报告。
- `/upload <文件路径>`：上传本地 MD/TXT（≤24 KB）到当前项目知识库。
- `/tools`：展开/收起最近工具事件。
- `/history`：输出历史轮次报告。
- `/resume`：恢复可继续的任务。
- `/continue [补充指令]`：在当前项目中，根据上一轮报告的“下一步所需证据”创建新的研究轮次。例如 `/continue` 或 `/continue 优先查找近三年的对照实验`。指令可省略，模型会结合证据缺口和指令规划检索、生成新报告；检索仍需审批。每次命令推进一轮，不会无限自动运行。报告缺少该章节时使用保存的未解决问题；没有报告或证据缺口时提示补充问题，当前轮次未结束时不能继续。
- `/quit`：退出 CLI。

研究最多取证五轮，缺证时继续补查；超时、工具故障或拒绝仍会结束并保留阶段结果。模型调用上限 28、文本预留单位上限 3200000，可能比旧策略更慢且费用更高。报告末尾列出联网检索的标题和实际 URL；检索出处不等于所有内容都已独立核实。

调用记录默认逐条可见，长输出显示省略行数。按 Ctrl+T 或输入 /tools 展开/收起完整输出，可滚动查看早期调用。耗时仅在事件时间戳可配对时显示。

项目外仅显示首页占位和操作选项，返回首页会清空上一项目的内容。输入 `/op` 等命令前缀会显示灰色后缀，Tab 接受；补全不处理参数。

调用默认显示简短摘要，Ctrl+T 或 /tools 查看完整输出。ready 表示待执行，只有 running 显示运行动画；打开项目不会自动恢复任务，恢复需显式 /resume。

`/save` 将最新已结束轮次的报告保存为 Markdown，默认目录为启动 `pnpm cli` 的目录；`/save ./reports` 或 `/save "含空格的目录"` 指定目录，支持 `~/`，不存在的目录会创建。文件名包含项目 ID 和随机标识，不覆盖旧导出；保存的是完整报告字符串（含来源），不包含 UI 调用日志。当前轮尚在生成时使用最近历史报告；没有可保存报告时提示错误。失败轮次的阶段报告仍保留其未核验说明。

内容区底部固定显示运行/审批/完成状态。调用标题为蓝色，辅助信息淡紫色，调用之间空一行；选项菜单中当前项使用灰色背景。主题与终端颜色能力可能影响实际色彩。
