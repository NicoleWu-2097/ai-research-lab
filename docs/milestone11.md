# M11：过程视图与联网搜索

使用 M10 的持久化审批模式。页面显示研究节点、累计模型调用/文本预留/重试、来源与引用、错误报告，以及可展开详情的事件时间线。研究和 A2A 事件写入 PostgreSQL 审计，刷新后可以补载。

事件接口为 `GET /api/research/tasks/:id/events?after=序号`，必须提供 `x-research-key`；也接受 Last-Event-ID。它返回有限批次 SSE，页面每次状态刷新后按游标拉取增量，失败后自动重试。连接关闭不会取消后台研究。原普通研究流仍是请求生命周期，不支持历史回放；完整过程视图使用人工模式。

联网搜索配置：HUMAN_ENABLED=true、WEB_SEARCH_ENABLED=true、BRAVE_SEARCH_API_KEY=你的密钥。保持 M9 所需开关开启。密钥仅保存在 API 环境变量；用户现有配置不会被自动修改。

选择 Brave 官方 Web Search API，查询和认证方式见 [官方文档](https://api-dashboard.search.brave.com/api-reference/web/search/get)。创建研究后由规划选择 web，本地检索和 MCP 仍可用；每次外发查询前有人工确认。最多两次 web 查询，共享三轮取证、八段来源和模型预算。查询超过提供方长度限制会失败。

当前保存的是搜索结果摘要，附 URL、标题、时间及摘要哈希，页面明确标记为非网页全文；不抓取任意结果 URL。引用校验仅保证引文在摘要快照中，不能证明网页全文支持结论。无密钥时保持搜索关闭；真实搜索需要用户自己的 Brave 凭证。

## 终端式工作台

界面采用等宽字体、浅色背景、细分隔线与紧凑状态栏。任务问题和执行事件按对话呈现，审批卡片嵌入流程，支持修改查询、批准或拒绝。来源、引用和原始事件详情可展开；新研究输入放在底部。窄屏自动收紧边距和换行，交互控件保留焦点提示。当前仍为单个研究任务的工作台，不提供多轮上下文聊天。

报告采用预览优先：研究者生成文本后显示“初稿，尚未完成核验”；结构化分析、引文或审查失败时保留待核验报告，并列出不确定之处。引用编号无效时标记无效，不能当作已核验来源；完成状态表示执行结束，报告上的核验标签表示证据质量。没有生成文本的服务错误仍可能无法提供报告。

终端布局更新：主内容为独立滚动的只读输出，新事件及报告变化时自动到底。审批、恢复、刷新和输入统一置于固定底部操作区；等待审批时直接显示审批输入。来源直接显示为文本，不要求向上展开或操作。
